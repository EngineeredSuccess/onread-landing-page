- Red flag icons pop in with "boing" SFX, scale 0→1.2→1

## Common Shot List (Across All Scripts)

### Shot 1: Text Conversation Reveal
- **Transition:** Glitch in from black (0.3s)
- **Animation:** Each text bubble slides in from right with 60ms delay between bubbles
- **Audio:** Light "ping" per message
- **CapCut effect:** Slide in with bounce

### Shot 2: Phone Reveal (User Opens OnRead)
- **Transition:** Screen rotation/orbit (0.5s)
- **Animation:** Phone model rotates to show app icon, then zoom to screen
- **Audio:** Whoosh + UI unlock sound
- **CapCut effect:** 3D rotate + zoom, lens flare on icon

### Shot 3: Analyzing Sequence
- **Transition:** Screen wipe with glitch (0.3s)
- **Animation:** Terminal-style output, progress bar fills with steps
- **Audio:** Beeping terminal sounds + electronic buildup
- **CapCut effect:** Scan line overlay (video), RGB split

### Shot 4: Verdict Card Reveal
- **Transition:** Snap zoom (0.4s)
- **Animation:** Card drops from top, springs, each section fades in
- **Audio:** Sting then silence
- **CapCut effect:** Spring physics, shake on "ROAST"

### Shot 5: Roast Text Reveal
- **Transition:** Typewriter (per word)
- **Animation:** Each word pops in with slight delay
- **Audio:** Typewriter keys + SFX on key words
- **CapCut effect:** Word-by-word appear, scale pop on important words

### Shot 6: Aura Score
- **Transition:** Flash (0.1s black)
- **Animation:** Number rolls from 0 → target → pulse
- **Audio:** Slot machine roll → coin drop → heartbeat
- **CapCut effect:** Number roll animation, neon pulse

### Shot 7: Red Flags Pop
- **Transition:** Staggered (0.3s between each)
- **Animation:** Each flag icon scales 0→1.2→1, "boing" effect
- **Audio:** Pop SFX per flag
- **CapCut effect:** Elastic scale, shake

### Shot 8: Call to Action
- **Transition:** Fade (0.5s)
- **Animation:** QR code scan lines, logo glow
- **Audio:** Positive "ding" + gentle loop
- **CapCut effect:** QR pulse, logo neon glow

### Shot 9: Final Frame
- **Transition:** Freeze + glitch
- **Static elements:** App logo + "onread.app" + QR code
- **CapCut effect:** Subtle VHS noise, scan lines
