## Production Order Recommendation

**Day 1:** Build mockups in Figma → export all PNGs
**Day 2:** Import everything into CapCut → apply master template
**Day 3:** Record/script text messages → animate conversation flow
**Day 4:** Add SFX + captions + roast timing
**Day 5:** Export test → review on phone → adjust → batch export remaining scripts

**Goal:** First video live within 72 hours of starting.
