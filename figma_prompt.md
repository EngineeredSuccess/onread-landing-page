````
Layers: name all, mark exports, color styles: #FF006E pink, #39FF14 green, #BC13FE purple, #0A0A0A black, #1A1A1A dark, #FF2D2D red.
````

**~850 characters — fits Figma's 2000 char limit with room to spare.**

To use:
1. **Figma web/app:** Select frame → Paste directly onto canvas → Use as spec while building
2. **Figma AI (beta):** Paste into the AI prompt field (Figma will auto-generate screens)
3. **FigJam:** Good for collaborative planning before building in Figma

**Pro tip:** If Figma AI generates the screens, the prompt structure naturally creates separate frames for each screen. You can then split them into pages (Design System, Screens, Components, Exports).
